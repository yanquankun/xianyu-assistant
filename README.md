# 闲鱼上架助手

闲鱼上架助手是一个基于 Chrome Side Panel 的浏览器扩展。它可以读取淘宝、天猫和京东商品页的公开信息，生成可编辑草稿，通过 OpenAI 兼容接口整理文案，并把用户确认后的标题、价格、描述、图片和视频填入闲鱼发布页。视频控件无法可靠识别时，扩展会提示用户在闲鱼页面手动上传。

扩展只负责整理和填表，不会点击闲鱼最终“发布”按钮。最终内容必须由用户在闲鱼页面检查并手动发布。

## 当前功能

- 在 Chrome 侧边栏中完成商品整理、AI 配置和运行记录查看。
- 解析淘宝、天猫和京东链接中的标题、价格、描述与图片。
- 接受淘宝、天猫和京东完整分享文案，以及淘宝/天猫共用的 `e.tb.cn`、京东的 `3.cn` 短链；解析成功后同时记录提交链接和最终规范链接，错误页不会生成草稿。
- 支持用户直接修改解析后的标题、售价、原价、描述、发货方式和分类备注；发货方式与闲鱼保持一致，并可配置一口价邮费和是否支持自提。
- 支持 OpenAI Chat Completions 兼容接口，可配置 Base URL、API Key、模型、Temperature 和补充要求。
- AI 润色会结合当前草稿的来源平台、标题、售价、原价、描述、发货方式、邮费、自提选项和分类备注识别当前商品，不发送商品链接、媒体画面、内部警告或其他原始数据；最终只写回商品描述。生成文案第一行是整理后的商品名称，后续以“字段：内容”格式逐行展示已知信息；未提供的成色、出售原因、购买时间或注意事项等字段整行省略。内置提示词会清理电商平台和促销话术，且约束模型不得编造成色、使用情况或售后承诺。生成内容会以打字机效果逐字显示；首个分片返回前显示“等待 AI 响应…”，开始输出后状态收至输入框右上角并显示“正在生成…”。状态层背景完全透明且自适应输入框尺寸，不遮挡后方生成文字。生成期间可停止并恢复原文，完成后可经确认恢复初始描述。
- 支持批量上传本地图片和多个本地视频；图片与视频合计最多 9 个，单个视频上限 100 MB。本地媒体保存在扩展 IndexedDB 中，关闭并重开侧边栏后仍可恢复。
- 图片或视频保存期间，对应上传按钮显示“上传中…”并暂时禁用媒体上传，避免重复提交。
- 草稿中的所有媒体都会填入闲鱼；不需要的媒体由用户点击卡片右上角删除。填入前必须至少有一张已加载的图片，视频可选。
- 填表前检查闲鱼登录状态，并提供手动刷新按钮；未登录时提示用户打开登录页。
- 编辑区显示步骤 `02`；“返回选择方式”会清除当前草稿和本地媒体，但保留 AI 配置与运行记录。
- 优先复用当前闲鱼页面；没有闲鱼页面时才打开发布页。
- 只填充闲鱼表单，不执行最终发布动作。
- 运行记录以当时的商品标题为主标题，可展开查看来源链接、字段完成度、可用的商品图片、表单快照、警告与结果；图片获取失败时会自动隐藏，快照会脱敏且不会随当前草稿变化。可在运行记录标题区删除当前浏览器保存的全部记录，删除前会二次确认。

## 使用边界

- 仅支持 Chrome 116 及以上版本。
- 淘宝、天猫、京东和闲鱼可能随时调整页面结构。扩展包含结构化数据、Open Graph 和常见 DOM 选择器等多级降级策略，但不能保证所有商品都能完整解析或填入。
- 不处理验证码，不自动登录，不绕过站点风控，不读取浏览器 Cookie。
- 不保证 AI 生成内容完全准确。价格、成色、真伪、售后和其他交易声明必须由用户核对。
- 测试使用匿名本地夹具，不代表已在真实淘宝、天猫、京东或闲鱼账户中完成回归。
- 自动化未执行真实视频上传，也未使用真实 100 MB 文件；真实闲鱼视频控件兼容性由用户人工验证。

## 环境要求

- Node.js 22 或更高版本
- pnpm 11.19.0
- Chrome 116 或更高版本

安装依赖：

```bash
pnpm install
```

## 本地开发

启动 WXT 开发模式：

```bash
pnpm dev
```

该命令不会另开临时浏览器，而是把开发版扩展直接输出到可见目录：

```text
dev-dist/xianyu-assistant-unpacked/
```

第一次使用时，在日常 Chrome 的 `chrome://extensions` 中开启“开发者模式”，选择“加载已解压的扩展程序”，然后选择该目录。保持 `pnpm dev` 运行；修改源码后，WXT 会实时重新构建，并自动热更新页面或重新加载扩展。

## 构建和打包

生成 CRX 安装包和 Chrome 应用商店 ZIP：

```bash
pnpm build
```

构建产物为：

```text
dist/xianyu-assistant-<version>-chrome.zip
dist/xianyu-assistant-<version>-chrome.crx
.output/chrome-mv3/
```

前两个文件分别是商店上传包和 CRX；`.output/chrome-mv3` 是本次生产构建使用的解压目录。`pnpm build` 不会在 `dist` 中额外复制解压目录。

首次构建时，Chrome 会生成用于保持扩展 ID 稳定的私钥：

```text
.keys/xianyu-assistant.pem
```

`.keys` 已被 Git 忽略。请安全备份该私钥；丢失后重新打包会产生新的扩展 ID。后续构建会自动复用它。

CRX 由本机 Google Chrome 打包。脚本会自动查找常见 Chrome 路径；使用非标准安装路径时，可以通过 `CHROME_BINARY` 指定可执行文件。ZIP 用于上传 Chrome 应用商店。普通 macOS 和 Windows Chrome 可能阻止直接安装本地 CRX，这是 Chrome 的分发限制，不代表 CRX 生成失败。

如果需要检查生产版解压内容，可执行：

```bash
pnpm build:unpacked
```

该命令会生成 `dist/xianyu-assistant-unpacked`，只用于生产构建的本地检查。日常开发应使用 `pnpm dev` 和 `dev-dist/xianyu-assistant-unpacked`。`pnpm zip` 保留为 `pnpm build` 的兼容别名。完整步骤见 [本地安装与验证](docs/本地安装与验证.md)。

## AI 配置

在侧边栏的“AI 配置”页填写：

- Base URL：OpenAI 兼容服务的 API 根地址，例如以 `/v1` 结尾的地址。
- API Key：对应服务的访问密钥。
- Model：服务端支持的模型名称。
- Temperature：允许范围为 0 到 2。
- 补充要求：对文案语气和内容边界的额外要求。

扩展会向 `Base URL/chat/completions` 发送请求。连接测试使用普通 Chat Completions JSON 响应；AI 润色使用 `stream: true`，要求服务通过 Server-Sent Events 返回 `choices[].delta.content`，并兼容 `data: [DONE]` 结束标记。

当 Base URL 使用 DeepSeek 官方域名时，AI 润色会关闭思考模式并限制生成规模。闲鱼描述整理不需要长推理，这也可以避免 `reasoning_content` 占用大量流式响应空间；其他 OpenAI Chat Completions 兼容接口不会收到 DeepSeek 专用参数。

远程 AI Base URL 必须使用 HTTPS，防止 API Key 通过明文 HTTP 传输。仅本机开发用的 `localhost`、`*.localhost`、`127.0.0.1` 和 `::1` 允许使用 HTTP。

API Key 只保存在当前浏览器扩展的本地存储中，不写入仓库，也不会出现在运行日志中。它仍然属于本机敏感数据：请勿共享 Chrome Profile，并在不再使用时移除扩展或清除扩展数据。

## 使用流程

1. 在 Chrome 工具栏点击扩展图标打开侧边栏。
2. 在“AI 配置”中保存并测试 OpenAI 兼容接口。
3. 打开淘宝、天猫或京东商品页，粘贴完整商品链接或客户端分享文案；如果没有来源链接，也可以点击“手动填写”创建空白草稿。
4. 点击“解析商品”，检查标题、价格、描述和图片。短链解析后同时核对提交链接与最终规范链接。
5. 根据需要批量上传本地图片或多个本地视频并预览媒体；图片与视频合计最多 9 个，也可以不添加媒体。所有保留在草稿中的媒体都会用于填表，不需要的媒体请点击右上角删除。
6. 根据需要手动编辑，或点击“AI 润色”；生成时可点击“停止润色”恢复原描述，成功后可点击“恢复”并确认回退到初始描述。AI 只改写商品描述，请立即复核生成结果。
7. 确保闲鱼网页已经登录；状态不准确时点击“刷新闲鱼登录状态”，然后点击“填入闲鱼”。
8. 在闲鱼发布页核对所有字段。若侧边栏提示视频未自动填入，由用户手动选择视频。
9. 手动补充分类、规格、运费、交易方式等站点字段。
10. 由用户自己点击闲鱼最终“发布”按钮。

Chrome 决定原生侧边栏位于浏览器左侧还是右侧。扩展不能强制右侧；当检测到左侧布局时，界面会提示用户在 Chrome 的侧边栏设置中调整。
