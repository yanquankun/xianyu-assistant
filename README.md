# 闲鱼上架助手

闲鱼上架助手是一个基于 Chrome Side Panel 的浏览器扩展。它可以读取淘宝、天猫和京东商品页的公开信息，生成可编辑草稿，通过 OpenAI 兼容接口整理文案，并把用户确认后的标题、价格、描述和图片填入闲鱼发布页。

扩展只负责整理和填表，不会点击闲鱼最终“发布”按钮。最终内容必须由用户在闲鱼页面检查并手动发布。

## 当前功能

- 在 Chrome 侧边栏中完成商品整理、AI 配置和运行记录查看。
- 解析淘宝、天猫和京东链接中的标题、价格、描述与图片。
- 支持用户直接修改解析后的标题、价格、描述、发货方式和分类备注。
- 支持 OpenAI Chat Completions 兼容接口，可配置 Base URL、API Key、模型、Temperature 和补充要求。
- AI 结果先进入预览，不会直接覆盖草稿；用户确认后才应用。
- 填表前检查闲鱼登录状态，未登录时提示用户打开登录页。
- 优先复用当前闲鱼页面；没有闲鱼页面时才打开发布页。
- 只填充闲鱼表单，不执行最终发布动作。
- 操作失败时保留草稿，并在本地运行记录中保存脱敏后的结果。

## 使用边界

- 仅支持 Chrome 116 及以上版本。
- 淘宝、天猫、京东和闲鱼可能随时调整页面结构。扩展包含结构化数据、Open Graph 和常见 DOM 选择器等多级降级策略，但不能保证所有商品都能完整解析或填入。
- 不处理验证码，不自动登录，不绕过站点风控，不读取浏览器 Cookie。
- 不保证 AI 生成内容完全准确。价格、成色、真伪、售后和其他交易声明必须由用户核对。
- 测试使用匿名本地夹具，不代表已在真实淘宝、京东或闲鱼账户中完成回归。

## 环境要求

- Node.js 22 或更高版本
- pnpm 11.19.0
- Chrome 116 或更高版本

安装依赖：

```bash
pnpm install
```

## 本地开发

启动 WXT 开发模式：

```bash
pnpm dev
```

该命令会生成开发版扩展并启动监听。若本机没有自动打开扩展调试浏览器，可在 `chrome://extensions` 中开启“开发者模式”，选择“加载已解压的扩展程序”，然后选择 `.output/chrome-mv3-dev`。

## 构建和打包

生成生产版解压目录：

```bash
pnpm build
```

生产目录为：

```text
.output/chrome-mv3
```

生成可分发 ZIP：

```bash
pnpm zip
```

ZIP 文件生成在 `.output` 目录。完整的 Chrome 加载步骤见 [本地安装与验证](docs/本地安装与验证.md)。

## AI 配置

在侧边栏的“AI 配置”页填写：

- Base URL：OpenAI 兼容服务的 API 根地址，例如以 `/v1` 结尾的地址。
- API Key：对应服务的访问密钥。
- Model：服务端支持的模型名称。
- Temperature：允许范围为 0 到 2。
- 补充要求：对文案语气和内容边界的额外要求。

扩展会向 `Base URL/chat/completions` 发送请求，并要求服务返回 JSON 对象。若供应商不兼容 Chat Completions 请求体或 `response_format` 参数，需要由供应商侧提供兼容入口。

远程 AI Base URL 必须使用 HTTPS，防止 API Key 通过明文 HTTP 传输。仅本机开发用的 `localhost`、`*.localhost`、`127.0.0.1` 和 `::1` 允许使用 HTTP。

API Key 只保存在当前浏览器扩展的本地存储中，不写入仓库，也不会出现在运行日志中。它仍然属于本机敏感数据：请勿共享 Chrome Profile，并在不再使用时移除扩展或清除扩展数据。

## 使用流程

1. 在 Chrome 工具栏点击扩展图标打开侧边栏。
2. 在“AI 配置”中保存并测试 OpenAI 兼容接口。
3. 打开淘宝、天猫或京东商品页并粘贴完整商品链接；如果没有来源链接，也可以点击“手动填写”创建空白草稿。
4. 点击“解析商品”，检查标题、价格、描述和图片。
5. 根据需要手动编辑，或点击“AI 扩写”并在预览中确认是否应用。
6. 确保闲鱼网页已经登录，然后点击“填入闲鱼”。
7. 在闲鱼发布页核对所有字段，手动补充扩展未识别的选项。
8. 由用户自己点击闲鱼最终“发布”按钮。

Chrome 决定原生侧边栏位于浏览器左侧还是右侧。扩展不能强制右侧；当检测到左侧布局时，界面会提示用户在 Chrome 的侧边栏设置中调整。

## 权限说明

| 权限                        | 用途                                                    |
| --------------------------- | ------------------------------------------------------- |
| `sidePanel`                 | 在 Chrome 原生侧边栏中显示界面                          |
| `storage`                   | 本地保存 AI 配置、草稿相关状态和脱敏运行记录            |
| `activeTab`                 | 识别并优先使用当前标签页                                |
| `scripting`                 | 在用户授权的商品页中运行解析脚本                        |
| `tabs`                      | 查找、复用、打开和关闭扩展自己创建的临时标签页          |
| `https://www.goofish.com/*` | 检测闲鱼登录状态并填写发布表单                          |
| 可选 HTTP/HTTPS 来源权限    | 在用户操作时访问指定商品页、AI 接口和选中图片的精确来源 |

扩展不会申请 Cookie、浏览历史或调试器权限。运行时权限被拒绝时，当前草稿不会被清空。

## 质量检查

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
pnpm zip
```

`pnpm test:e2e` 使用独立 Chromium Profile、匿名商品夹具、本地 AI 接口和模拟闲鱼页面，验证解析、AI 预览、登录提示、表单填充以及最终发布按钮未被点击。它不会读取日常 Chrome Profile，也不会访问真实闲鱼账户。

无头端到端测试直接打开扩展的 `sidepanel.html`，并在测试专用 Manifest 中预授权夹具来源。因此，工具栏图标打开原生 Side Panel、Chrome 权限弹窗的允许与拒绝流程仍属于人工验收项，不能由当前自动化结果代替。

## 项目结构

```text
entrypoints/            WXT 扩展入口，包括后台、侧边栏和内容脚本
src/ai/                 OpenAI 兼容客户端、提示词和输出校验
src/background/         权限、标签页选择和消息编排
src/parsers/            淘宝、京东和通用结构化数据解析
src/sidepanel/          React 侧边栏界面和工作流状态
src/storage/            本地存储与脱敏运行记录
src/xianyu/             登录检测、发布页选择和安全填表
tests/unit/             单元与组件测试
tests/e2e/              隔离浏览器端到端测试
```

## 安全约束

- 运行时消息联合类型中不存在“发布”或“点击发布”动作。
- 闲鱼填表脚本只查找输入框、文本域和文件输入框。
- 商品解析临时标签页只由扩展在必要时创建，并在解析结束后关闭；不会关闭用户已有页面。
- 图片下载仅接受 JPEG、PNG 和 WebP；每次最多处理 9 张，单张上限 10 MB，原始数据总量上限 20 MB。
- 运行日志会移除 API Key、Authorization、Cookie 和 URL 用户信息，最多保留 100 条。
