# 闲鱼上架助手

闲鱼上架助手是一个基于 Chrome Side Panel 的浏览器扩展。它可以读取淘宝、天猫和京东商品页的公开信息，生成可编辑草稿，通过 OpenAI 兼容接口整理文案，并把用户确认后的标题、价格、描述和本地图片填入闲鱼发布页。草稿也可以保存一个本地视频；视频控件无法可靠识别时，扩展会提示用户在闲鱼页面手动上传。

扩展只负责整理和填表，不会点击闲鱼最终“发布”按钮。最终内容必须由用户在闲鱼页面检查并手动发布。

## 当前功能

- 在 Chrome 侧边栏中完成商品整理、AI 配置和运行记录查看。
- 解析淘宝、天猫和京东链接中的标题、价格、描述与图片。
- 接受淘宝、京东完整分享文案，以及 `e.tb.cn`、`3.cn` 短链；解析成功后同时记录提交链接和最终规范链接，错误页不会生成草稿。
- 支持用户直接修改解析后的标题、价格、描述、发货方式和分类备注。
- 支持 OpenAI Chat Completions 兼容接口，可配置 Base URL、API Key、模型、Temperature 和补充要求。
- AI 扩写期间显示加载状态；合法结果会直接写回标题和描述，不再经过独立预览确认。
- 支持一次批量上传本地图片；解析图片与本地图片合计最多选择 9 张。本地媒体保存在扩展 IndexedDB 中，关闭并重开侧边栏后仍可恢复。
- 支持保存、替换、移除和预览一个 MP4 或 MOV 视频；单视频上限 100 MB。
- 填表前检查闲鱼登录状态，并提供手动刷新按钮；未登录时提示用户打开登录页。
- 编辑区显示步骤 `02`；“返回选择方式”会清除当前草稿和本地媒体，但保留 AI 配置与运行记录。
- 优先复用当前闲鱼页面；没有闲鱼页面时才打开发布页。
- 只填充闲鱼表单，不执行最终发布动作。
- 运行记录以当时的商品标题为主标题，可展开查看来源链接、标题、描述、价格、媒体摘要、警告与结果；快照会脱敏且不会随当前草稿变化。

## 使用边界

- 仅支持 Chrome 116 及以上版本。
- 淘宝、天猫、京东和闲鱼可能随时调整页面结构。扩展包含结构化数据、Open Graph 和常见 DOM 选择器等多级降级策略，但不能保证所有商品都能完整解析或填入。
- 不处理验证码，不自动登录，不绕过站点风控，不读取浏览器 Cookie。
- 不保证 AI 生成内容完全准确。价格、成色、真伪、售后和其他交易声明必须由用户核对。
- 测试使用匿名本地夹具，不代表已在真实淘宝、京东或闲鱼账户中完成回归。
- 自动化未执行真实视频上传，也未使用真实 100 MB 文件；真实闲鱼视频控件兼容性由用户人工验证。

## 环境要求

- Node.js 22 或更高版本
- pnpm 11.19.0
- Chrome 116 或更高版本

安装依赖：

```bash
pnpm install
```

## 本地开发

启动 WXT 开发模式：

```bash
pnpm dev
```

该命令不会另开临时浏览器，而是把开发版扩展直接输出到可见目录：

```text
dev-dist/xianyu-assistant-unpacked/
```

第一次使用时，在日常 Chrome 的 `chrome://extensions` 中开启“开发者模式”，选择“加载已解压的扩展程序”，然后选择该目录。保持 `pnpm dev` 运行；修改源码后，WXT 会实时重新构建，并自动热更新页面或重新加载扩展。

## 构建和打包

生成 CRX 安装包和 Chrome 应用商店 ZIP：

```bash
pnpm build
```

构建产物为：

```text
dist/xianyu-assistant-0.1.0-chrome.zip
dist/xianyu-assistant-0.1.0-chrome.crx
.output/chrome-mv3/
```

前两个文件分别是商店上传包和 CRX；`.output/chrome-mv3` 是本次生产构建使用的解压目录。`pnpm build` 不会在 `dist` 中额外复制解压目录。

首次构建时，Chrome 会生成用于保持扩展 ID 稳定的私钥：

```text
.keys/xianyu-assistant.pem
```

`.keys` 已被 Git 忽略。请安全备份该私钥；丢失后重新打包会产生新的扩展 ID。后续构建会自动复用它。

CRX 由本机 Google Chrome 打包。脚本会自动查找常见 Chrome 路径；使用非标准安装路径时，可以通过 `CHROME_BINARY` 指定可执行文件。ZIP 用于上传 Chrome 应用商店。普通 macOS 和 Windows Chrome 可能阻止直接安装本地 CRX，这是 Chrome 的分发限制，不代表 CRX 生成失败。

如果需要检查生产版解压内容，可执行：

```bash
pnpm build:unpacked
```

该命令会生成 `dist/xianyu-assistant-unpacked`，只用于生产构建的本地检查。日常开发应使用 `pnpm dev` 和 `dev-dist/xianyu-assistant-unpacked`。`pnpm zip` 保留为 `pnpm build` 的兼容别名。完整步骤见 [本地安装与验证](docs/本地安装与验证.md)。

## AI 配置

在侧边栏的“AI 配置”页填写：

- Base URL：OpenAI 兼容服务的 API 根地址，例如以 `/v1` 结尾的地址。
- API Key：对应服务的访问密钥。
- Model：服务端支持的模型名称。
- Temperature：允许范围为 0 到 2。
- 补充要求：对文案语气和内容边界的额外要求。

扩展会向 `Base URL/chat/completions` 发送请求，并要求服务返回 JSON 对象。若供应商不兼容 Chat Completions 请求体或 `response_format` 参数，需要由供应商侧提供兼容入口。

远程 AI Base URL 必须使用 HTTPS，防止 API Key 通过明文 HTTP 传输。仅本机开发用的 `localhost`、`*.localhost`、`127.0.0.1` 和 `::1` 允许使用 HTTP。

API Key 只保存在当前浏览器扩展的本地存储中，不写入仓库，也不会出现在运行日志中。它仍然属于本机敏感数据：请勿共享 Chrome Profile，并在不再使用时移除扩展或清除扩展数据。

## 使用流程

1. 在 Chrome 工具栏点击扩展图标打开侧边栏。
2. 在“AI 配置”中保存并测试 OpenAI 兼容接口。
3. 打开淘宝、天猫或京东商品页，粘贴完整商品链接或客户端分享文案；如果没有来源链接，也可以点击“手动填写”创建空白草稿。
4. 点击“解析商品”，检查标题、价格、描述和图片。短链解析后同时核对提交链接与最终规范链接。
5. 根据需要批量上传本地图片、添加一个本地视频并预览媒体；图片最多选择 9 张。
6. 根据需要手动编辑，或点击“AI 扩写”；成功结果会直接写入表单，请立即复核。
7. 确保闲鱼网页已经登录；状态不准确时点击“刷新闲鱼登录状态”，然后点击“填入闲鱼”。
8. 在闲鱼发布页核对所有字段。若侧边栏提示视频未自动填入，由用户手动选择视频。
9. 手动补充分类、规格、运费、交易方式等站点字段。
10. 由用户自己点击闲鱼最终“发布”按钮。

Chrome 决定原生侧边栏位于浏览器左侧还是右侧。扩展不能强制右侧；当检测到左侧布局时，界面会提示用户在 Chrome 的侧边栏设置中调整。

## 权限说明

| 权限                        | 用途                                                    |
| --------------------------- | ------------------------------------------------------- |
| `sidePanel`                 | 在 Chrome 原生侧边栏中显示界面                          |
| `storage`                   | 本地保存 AI 配置、草稿相关状态和脱敏运行记录            |
| `unlimitedStorage`          | 提高扩展域 IndexedDB 保存本地媒体时的可用存储配额       |
| `activeTab`                 | 识别并优先使用当前标签页                                |
| `scripting`                 | 在用户授权的商品页中运行解析脚本                        |
| `tabs`                      | 查找、复用、打开和关闭扩展自己创建的临时标签页          |
| `https://www.goofish.com/*` | 检测闲鱼登录状态并填写发布表单                          |
| 可选 HTTP/HTTPS 来源权限    | 在用户操作时访问指定商品页、AI 接口和选中图片的精确来源 |

扩展不会申请 Cookie、浏览历史或调试器权限。运行时权限被拒绝时，当前草稿不会被清空。

## 质量检查

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
```

`pnpm test:e2e` 使用独立 Chromium Profile、匿名商品与短链夹具、本地 AI 接口和模拟闲鱼页面，验证 AI 加载后直接回填、步骤返回、登录刷新、运行记录详情、两张本地图片上传/预览/恢复、分享文案与错误页保护、表单填充以及最终发布按钮未被点击。它不会读取日常 Chrome Profile，也不会访问真实淘宝、京东短链或闲鱼账户。

视频只保留轻量单元测试覆盖；端到端自动化不上传视频。真实 MP4/MOV、接近 100 MB 边界和真实闲鱼视频控件均由用户人工验证。

无头端到端测试直接打开扩展的 `sidepanel.html`，并在测试专用 Manifest 中预授权夹具来源。因此，工具栏图标打开原生 Side Panel、Chrome 权限弹窗的允许与拒绝流程仍属于人工验收项，不能由当前自动化结果代替。

## 项目结构

```text
entrypoints/            WXT 扩展入口，包括后台、侧边栏和内容脚本
src/ai/                 OpenAI 兼容客户端、提示词和输出校验
src/background/         权限、标签页选择和消息编排
src/parsers/            淘宝、京东和通用结构化数据解析
src/sidepanel/          React 侧边栏界面和工作流状态
src/storage/            本地存储与脱敏运行记录
src/xianyu/             登录检测、发布页选择和安全填表
tests/unit/             单元与组件测试
tests/e2e/              隔离浏览器端到端测试
```

## 安全约束

- 运行时消息联合类型中不存在“发布”或“点击发布”动作。
- 闲鱼填表脚本只查找输入框、文本域和文件输入框。
- 商品解析临时标签页只由扩展在必要时创建，并在解析结束后关闭；不会关闭用户已有页面。
- 图片仅接受 JPEG、PNG 和 WebP；每次最多处理 9 张，单张上限 10 MB，已选本地图片总量上限 20 MB。视频仅接受 MP4 或 MOV，单文件上限 100 MB。
- 本地媒体只保存在扩展域 IndexedDB；只有用户点击“填入闲鱼”后才会传给当前闲鱼页面。
- 运行日志会移除 API Key、Authorization、Cookie 和 URL 用户信息，最多保留 100 条。
